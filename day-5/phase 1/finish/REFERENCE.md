# Phase 1 — Reference result

No code artifact for this phase. The reference result is:

- Three task-relevant skills found and bookmarked.
- At least one skill page inspected (source files read, not just the
  description).
- SkillSpector installed from its inspected NVIDIA source and
  `skillspector scan --help` run successfully.

The facilitator confirms participants can search and open skill pages
before moving to Phase 2.

## Optional top-three lab

The leaderboard changes over time, so the reference result records process,
not fixed scan scores:

- Refreshed the skills.sh **All Time** leaderboard.
- Recorded the three skill names, source repositories, and commit SHAs.
- Scanned every effective skill directory, including delegated skills.
- Read every file and separated scanner findings from manual-review findings.
- Recorded an install or do-not-install decision with evidence.

This extension is outside the two-hour core route.
