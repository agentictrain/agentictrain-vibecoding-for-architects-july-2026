# Integration Architecture Copilot application

- `index.html` defines the semantic three-region shell, labeled controls,
  evidence views, live states, and workshop advisory output.
- `styles.css` provides the responsive visual system, evidence grids, distinct
  state treatments, and visible keyboard focus from 320 px upward.
- `app.js` owns in-memory state, Open-Meteo search and forecast calls,
  WeatherSignal mapping, explicit fictional fallback, model request and strict
  response validation, rendering, and events.

Open `index.html` directly in a browser. No server, package installation, build
step, persistence, or external library is required.
