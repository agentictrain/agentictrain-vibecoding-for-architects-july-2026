# Starter application files

- `index.html` defines the single-page shell and its three stable labeled
  regions.
- `styles.css` provides local responsive layout, contrast, and visible focus.
- `app.js` sets the starter status message and performs no network request.

Open `index.html` in a browser to inspect this checkpoint. The disabled actions
and empty output placeholders are intentional at the Day 2 starting state.
